#  AI Expense Tracker

An AI-powered Expense Tracker built with React that helps users manage income and expenses, visualize financial data, and receive AI-generated spending insights.

## Live Demo

   https://ai-expense-tracker-pied-two.vercel.app/

##  GitHub Repository

   https://github.com/vjnithish17/Ai-expense-tracker

##  Features

-  Add Income & Expenses
-  Edit Transactions
-  Delete Transactions
-  Dashboard with Financial Summary
-  Analytics & Charts
-  AI Spending Insights
-  Search & Filter Transactions
-  Responsive User Interface

##  Tech Stack

- React.js
- React Router DOM
- Axios
- JSON Server / REST API
- CSS3
- Recharts
- Groq AI API *(AI Insights feature)*

> **Note:** The AI Insights feature requires a valid Groq API key. If no valid API key is configured, AI responses will not be generated.
